# ElectraLensAI Tech Stack

## Frontend (Client)
- **Framework**: React 18, Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS (PostCSS)
- **Icons**: Lucide React
- **Data Visualization**: Recharts
- **Internationalization**: i18next, react-i18next, i18next-browser-languagedetector
- **Linting**: ESLint

## Backend (API & Orchestration)
- **Framework**: FastAPI (Python 3.12+)
- **Server**: Uvicorn
- **AI/Agents**: Google Agent Development Kit (ADK)
- **Foundation Models**: Gemini 2.5 Pro (Reasoning), Gemini 2.5 Flash (Routing)
- **Security**: Google Cloud Data Loss Prevention (DLP API)
- **Localization**: Google Cloud Translation API (v3)

## Infrastructure & DevOps
- **Containerization**: Docker
- **Deployment**: Google Cloud Run (Fully Managed)
- **CI/CD**: Google Cloud Build
- **Code Quality**: Ruff (Linter & Formatter), Bandit (Security Analysis)
- **Testing**: Pytest (Backend)
